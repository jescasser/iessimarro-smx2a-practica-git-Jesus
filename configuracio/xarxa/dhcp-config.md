# Configuració del servei DHCP

## Objectiu

Configurar el servei DHCP perquè els equips de l'aula digital reben automàticament una adreça IP.

## Rang d'adreces

- Adreça IP inicial: 192.168.1.10
- Adreça IP final: 192.168.1.50
- Porta d'enllaç: 192.168.1.1 (valor d'exemple, pendent de verificar amb l'Annex B).
- Servidor DNS: 192.168.1.1 (valor d'exemple, pendent de verificar amb l'Annex B).

## Procediment

1. Activar el servei DHCP en el dispositiu o servidor indicat en la pràctica.
2. Definir el rang d'adreces IP entre 192.168.1.10 i 192.168.1.50.
3. Configurar la porta d'enllaç i el servidor DNS correctes.
4. Guardar els canvis i comprovar que el servei estiga actiu.

## Verificació

Comprovar amb tres equips de prova que:

- Reben automàticament una adreça IP dins del rang configurat.
- Utilitzen la porta d'enllaç i el servidor DNS previstos.
- Poden comunicar-se amb els altres equips i amb els serveis de xarxa segons els requisits de la pràctica.

## Resultat

Registrar els resultats de les proves i anotar qualsevol incidència detectada.
